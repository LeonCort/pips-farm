# What engine files still take from the game, by name (all files share one scope).
# A game built on the engine must declare every name below, or the engine part that uses it fails.
# tools/refs.py --strict fails when an engine file starts using a game name that is not listed here,
# so this list can only shrink. Each line: name, then what it is for. Groups follow the plan doc.
#
# Shrinking it: move a name into the engine when every game needs the same thing (as kit.js, icons.js,
# fx.js and game.js did), or replace the use with a hook the game fills in.
